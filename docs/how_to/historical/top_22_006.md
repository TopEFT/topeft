# Historical TOP-22-006 reproduction

This page identifies the repository material retained for reproduction of the
published TOP-22-006 predecessor analysis. It is intentionally separate from
the current TOP-26-006 workflow. The repository does not establish, without
reopening historical campaign archaeology, that a fresh checkout and current
environment can reproduce every original production step unchanged.

## Preserved entry points

- `analysis/topeft_run2/fullR2_run.sh` is the historical Run 2 histogram
  wrapper. It is retained as an archival entry point; new Run 2 or Run 3 work
  uses `fullR3_run.sh` or a maintained `run_cr.sh` profile.
- `analysis/topeft_run2/datacards_post_processing.py --set-up-top22006` (`-s`)
  selects the historical TOP-22-006 card topology. This differs from the
  current full topology selected with `--all-analysis` (`-a`).
- [MC validation notes](top_22_006_mc_validation.md) describe the June 2022
  private-versus-central UL validation scripts.
- [JES regrouping notes](jet_energy_uncertainty_regrouping.md) record the
  one-time uncertainty payload preparation used by that analysis.

## Reproduction boundary

Before attempting historical execution, inspect the scripts and resolve their
environment, input dataset, payload, and external repository assumptions from
the historical record. Do not substitute current TOP-26-006 NDSkim configs,
sumw2 policy, binning, channel topology, or EFT scaling inputs and call the
result a TOP-22-006 reproduction. Conversely, do not use these historical
scripts as the primary instructions for current production.

The exact published reproduction campaign, environment reconstruction, and
production validation are outside the maintained current documentation
contract. This page preserves truthful entry-point ownership without inventing
steps that the present source does not establish.
